Charge point statuses
Available
The charge point is available for charging.
Maintenance
The charge point has been set in maintenance state by an owner/operator.
Error
Hardware or software error.
Disconnected
Connection to the charge point cannot be established.
Busy Non Released
Charge session is finished, but the cable has not been released. Charging cannot start again.
Busy Non Charging
Charge session is finished, but charging may continue later.
Other
Passive or unknown status.
Charging
A vehicle is charging at the charge point.
