API Documentation

Inputs

Input Type Default Description
size 'small' | 'standard' | 'large' 'standard' Controls the size of the button
type 'button' | 'submit' | 'reset' 'button' HTML button type attribute
variant 'primary' | 'secondary' | 'professional' | 'danger' 'primary' The color theme of the button
isLoading boolean false Shows a loading state and prevents interaction
outlined boolean false When true, uses an outlined (stroke) style
disabled boolean false When true, disables the button
fullWidth boolean false When true, button takes full width of container
ariaLabel string undefined Sets aria-label for accessibility

Outputs

Output Event Type Description
btnClick MouseEvent Emitted when button is clicked
btnFocus FocusEvent Emitted when button receives focus
btnBlur FocusEvent Emitted when button loses focus
btnKeydown KeyboardEvent Emitted on keydown event
btnKeyup KeyboardEvent Emitted on keyup event
btnMouseenter MouseEvent Emitted when mouse enters button
btnMouseleave MouseEvent Emitted when mouse leaves button
